# 机床界面中文清单

这里按现有界面逐项列出名称和用途，便于设计时核对有没有遗漏。所有机床动作目前只是演示，表中的“用途”说明正式使用时这个入口做什么。

先看 [图文说明](index.html)，也可以直接打开 [方便阅读的清单页面](controls.html)。

截图中的轴名、坐标编号、机床指令、键盘按键和原始文件名按画面保留；它们不是需要阅读的英文说明。

## 不熟悉的词怎么理解

这些解释帮助安排画面，不要求设计师掌握机床编程。

| 名称                 | 白话说明                                                           |
| -------------------- | ------------------------------------------------------------------ |
| 回零                 | 让机床找到自己的参考位置。                                         |
| 对刀                 | 建立工件或刀具的位置基准；工件对刀与刀具对刀是不同设置。           |
| 点动                 | 操作员手动移动某个轴。连续方式持续移动，步距方式每次移动一小段。   |
| 倍率                 | 相对于原设定的百分比。100% 表示原设定值，50% 表示一半。            |
| 主轴                 | 带动刀具或工件旋转的部分。                                         |
| 刀路                 | 刀具运动的路线。                                                   |
| 工件坐标、机床坐标   | 位置数字所采用的两种不同基准。                                     |
| 坐标偏置             | 将位置基准平移一段距离的修正值。                                   |
| 刀长补偿             | 修正不同刀具长度带来的差异。                                       |
| 实际位置、指令位置   | 系统反馈的位置，与控制指令要求的位置。                             |
| 剩余行程             | 当前这一段运动还没有走完的距离。                                   |
| 当前模态指令         | 目前持续生效的加工方式和参数。                                     |
| 关节模式、坐标轴模式 | 前者按运动机构区分，后者按空间方向区分；保留两个独立选择。         |
| 选择停、程序段跳过   | 前者决定遇到特定停止指令是否暂停；后者决定是否跳过带斜杠的程序段。 |
| 硬限位               | 机床到达行程边界时触发的限制。                                     |
| 单选、多选           | 圆圈通常表示一组中选一个；方框表示每一项可分别勾选。               |
| 只读                 | 只能看，不能在这里修改。                                           |
| 悬停、焦点           | 悬停是鼠标移到上面；焦点是键盘操作当前落到的位置。                 |
