# 轨迹规划

[全项目模块地图](../../../docs/module-map.md)

## 作用与语言

C；参与实时运动执行。

管理运动段队列，计算沿路径的速度、加减速和段间衔接，按周期提供规划结果。

## 关键代码与通信

`tp.h` 是规划接口；`tp.c` 是主体，`tc.c`、`tcq.c` 管运动段和队列，`blendmath.c` 管衔接计算，`tpmod.c` 提供模块装配。

由运动模块调用；接收直线、圆弧等运动段和约束，返回路径位置及执行状态。
