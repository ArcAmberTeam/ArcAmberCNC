# 实时运行环境适配

[全项目模块地图](../../docs/module-map.md)

## 作用与语言

C 为主，含部分 C++ 支持文件。

为实时模块提供任务、时间、共享内存等底层能力，适配具体的实时运行环境。

## 关键代码与通信

`rtapi.h`、`rtapi_app.h` 等为接口；`uspace_rtapi*`、`rtai_rtapi.c` 等为不同后端实现，具体选择由构建和运行配置决定。

被 HAL 与实时模块使用；目标部署采用 Debian 13 的 PREEMPT_RT 路径，但仍需目标机实际验证。

## 职责边界

RTAPI 不解释 G 代码，不计算机床几何，也不承载网页通信。历史无扩展名 `README` 包含旧平台和旧构建说明，不能直接当作当前 Debian 部署步骤。

这是保留的 LinuxCNC 核心代码，不属于当前 Web 静态构建产物。我们的 Python 服务尚未接入这些控制路径。此说明描述现有职责，不新增接口或改变上游依赖。

修改此处需要相应的 LinuxCNC 原生构建与功能验证；Web 或 Tauri 构建通过不能证明该模块可运行。涉及实时行为还需目标 Linux 主机验证。
