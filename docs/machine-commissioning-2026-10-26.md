## 已观察到的冲突

HOME ALL 期间，逻辑 X / joint 0 的指令与反馈位置变为约 −353.535，输出连接 stepgen.00；用户确认实际运动的是 275 mm Y。GPIO021 / joint 1 正限位持续触发，核心报告 `joint 1 on limit switch error`。随后机床未使能，回零进入中止状态。stepgen.01 对应的物理轴以及各通道的实际正负方向尚未核验。不能仅凭这些观察交换所有 X/Y 参数或反转输出。

## 软件门禁

专用机配置要求分别提供 `SWITCH_INPUTS_VERIFIED`、`MOTOR_MAPPING_VERIFIED`、`MOTOR_DIRECTIONS_VERIFIED`。后两项缺失或非 YES 时，控制服务拒绝单轴/全部回零及依赖回零的联动运动；GUI 显示原因。准备工具只生成配置，始终将电机两项标为 NO，不将输入开关测试或软件 CI 冒充运动验收。

下一步现场核验必须记录每个 stepgen 通道对应的物理轴、正向实际移动方向、限位位置及输入。受控验收结果应进入仓库评审及明确的配置迁移，再通过正式 Release 部署；当前包不自动交换输出或修改现有 INI/HAL。不要只为消除错误设置验收标记或覆盖硬限位。确认物理映射前保持自动回零禁用。

软件回归只在 GitHub CI 运行，不连接机床。安装、界面显示、连接状态通过不代表轴映射、回零或加工验收已完成。
