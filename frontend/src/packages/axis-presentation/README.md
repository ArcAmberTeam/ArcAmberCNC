# 跨区域展示对话框

[返回前端模块目录](../README.md) · [全项目模块地图](../../../../docs/module-map.md)

## 作用与语言

TypeScript、Pinia。

记录当前要打开的对话框及标题，按功能编号查找目录中的说明名称。

## 入口与内部文件

`index.ts` 导出 `useAxisPresentation`，提供 `dialog` 和 `openDialog`。

`lib/store.ts` 保存展示状态及目录查询逻辑；弹窗实际内容由界面组合模块呈现。

`lib/` 为私有实现。跨模块只能从根目录公开入口导入，不能直接引用内部文件；组件、状态和校验跟随本模块维护。

## 上下游与职责边界

只依赖 `axis-catalog`；供页面和功能模块调用。

不是全局机床状态仓库，不保存选轴、刀路几何、程序选中行，也不发送机床命令。

## 修改位置与验证

多个区域打开同一操作说明走这个入口；独属于某功能的状态留在该功能模块。

在 `frontend/` 运行 `npm run check` 和 `npm run build`；交互变化再运行 `npm run test:e2e` 并目视检查。不能为绕过检查而放宽模块依赖规则。
