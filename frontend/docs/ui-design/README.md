## 分成哪些类

| 分类               | 里面有什么                                         |
| ------------------ | -------------------------------------------------- |
| 整体布局与顶部按钮 | 窗口名称、功能菜单、常用操作按钮                   |
| 移动、回零与对刀   | 选轴、移动方向、移动距离、回零、工件对刀、刀具对刀 |
| 主轴与冷却         | 旋转方向、停止、转速加减、制动和冷却开关           |
| 速度与倍率         | 五组滑条，分别调节速度或百分比                     |
| 手动输入指令       | 历史记录、输入框、执行按钮和当前加工设置           |
| 刀路与位置显示     | 路线示意图、大号位置数字和位置修正信息             |
| 加工程序与底部状态 | 按行显示的程序、拖动分隔条、机床和刀具状态         |
| 弹出窗口与表格     | 文件选择、对刀设置、刀具表、说明信息等             |
| 常用小控件         | 按钮、标签、输入框、选择框、开关、滑条和弹出窗口   |

## 怎么看这些图片

“控件”就是屏幕上的按钮、输入框、开关等小部件。现有配色和排版可以重新设计，图片主要帮助看清内容和功能。

资料包含 8 张整页截图和 30 张局部截图。主界面参考大小为宽 1100、高 820 像素；另附较小和较大窗口。局部图来自高 1000 像素的窗口，便于展开菜单并看全内容。图片周边可能有少量留白，因此图片大小不等于按钮大小。

截图来自当前演示界面，机床控制还没有接通。坐标、程序和机床状态是样例；点按钮不会真的让设备动作。

## 截图里的字母是什么

- 轴名：几个运动方向的名称。
- 坐标编号：区分不同的工件位置基准。
- 机床指令：加工程序使用的内容，按原样展示即可。
- 键盘按键：说明可以按哪个键调用功能。
- 软件名称、文件名和示例图案：现有画面里的原始内容。

这些地方保留原样，正文均用中文解释。设计师不需要读懂或编写加工程序。

## 同一个控件有哪些样子

| 操作时刻       | 画面需要表达什么                       |
| -------------- | -------------------------------------- |
| 平时           | 没有操作时的基本样子                   |
| 鼠标移上去     | 提示这里可以操作                       |
| 按住按钮       | 表达正在按下，和普通状态有区别         |
| 已选中或已开启 | 表达当前选择，而不是正在按住           |
| 用键盘切到这里 | 用边框等方式标明键盘操作的位置         |
| 不能操作       | 表达当前不可点击、不可输入或不可拖动   |
| 输入错误       | 说明哪里填错、应该怎么改               |
| 没有内容       | 给出明确说明，不留一大片没有解释的空白 |

截图只包含当前已有的样子，其他状态需在新设计里补画。颜色变化应配合文字、图形或边框，让人能够明确识别。

## 最容易混淆的几个功能

- 回零是寻找机床参考位置；工件对刀是设置工件基准；刀具对刀是设置刀具修正。
- 急停是机床状态；未连接表示通信尚未建立，应分别表达。
- 主轴转速、加工前进速度和手动移动速度是不同的量。
- 百分比表示倍率；“毫米/分钟”表示速度，单位不能互换。
- 关闭弹出窗口不表示已经保存或执行。
