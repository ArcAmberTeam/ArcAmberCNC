# 前端视觉说明

当前操作界面采用参考 Linear 的深色工作台设计，保留项目自己的中文术语与机床功能。参考的是视觉层次、紧凑布局和克制的强调色，没有引入 Linear 服务、账户、品牌素材或新的前端框架。

## 布局

- 顶部：产品名称、当前位置和文件／机床／视图／帮助菜单；不显示左侧品牌图标。
- 程序信息：当前文件；不显示连接提示、演示标签或装饰状态灯。
- 工具栏：保留全部 19 个功能入口。急停使用红色和文字，运行使用紫色和文字，其余采用统一线性图标和中文提示。
- 左侧：手动操作、手动输入、点动、回零、对刀、主轴、冷却、速度与倍率。内容过长时独立滚动。
- 右侧：上方刀路或坐标数显，下方只读程序；中间分隔条支持拖动和键盘调整。缩小窗口时限制程序区高度，保留坐标和刀路空间。
- 底部状态栏已移除，工作区延伸至窗口底部。坐标和速度读数保留，示例回零标记已移除。

## 外观

| 内容           | 约定                                         |
| -------------- | -------------------------------------------- |
| 主背景         | 深石墨 `#151618`                             |
| 左侧操作区     | 更暗的 `#111214`                             |
| 浮层与普通按钮 | `#1c1d20`                                    |
| 主要文字       | `#ececef`                                    |
| 次要文字       | `#a4a6b0`                                    |
| 强调色         | 紫色 `#a29bfe`；主要按钮 `#6860d9`           |
| 急停提示       | 浅红文字 `#f58b8b` 配深红底色                |
| 形状           | 按钮 6 像素圆角，弹窗 12 像素圆角，细线分隔  |
| 数值           | 等宽数字，显示单位；不以装饰动画模拟数值变化 |

悬停通过背景和边框表达，选中使用浅紫文字与深紫底色，键盘焦点使用紫色轮廓，不可用控件降低明度。动画仅用于短暂的颜色过渡，并遵循系统“减少动态效果”设置。字体与图标全部使用本地资源，无远程字体或图标请求。

## 实现与验收

颜色与通用控件归 `ui-system`；业务区域的布局归各功能模块；页面只负责组合。历史 `TkButton` 等组件入口名称暂时保留，外观已经替换。历史图标文件和许可证继续保留，工具栏及主轴方向按钮使用原创 SVG 图标。

浏览器检查覆盖中文入口、菜单与弹窗、点动说明、手动输入、选轴、倍率、程序行选择、分隔条和最小窗口布局。设计参考尺寸为 1100 × 820，最小桌面尺寸为 760 × 640。目标 Debian 13 Intel 核显的实际显示仍需目标机验收。

这是界面演示，刀路与机床状态仍是样例。Python 服务连接成功只表示本地通信正常；所有机床动作继续显示未接入说明。
