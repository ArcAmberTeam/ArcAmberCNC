# 功能目录与演示数据

[返回前端模块目录](../README.md) · [全项目模块地图](../../../../docs/module-map.md)

## 作用与语言

TypeScript、G 代码样例。

保存菜单、工具栏、坐标轴、坐标系、快捷说明和固定演示程序。

## 入口与内部文件

`index.ts` 导出目录及样例；`model.ts` 定义 `MenuItem`、`ToolbarItem` 类型。

`lib/catalog.ts` 管功能入口；`lib/fixture.ts` 和 `lib/sample.ngc` 管样例。

`lib/` 为私有实现。跨模块只能从根目录公开入口导入，不能直接引用内部文件；组件、状态和校验跟随本模块维护。

## 上下游与职责边界

被功能模块和展示对话框模块读取；不依赖其他业务模块。

目录只是功能描述，不能执行命令；样例不代表实时坐标或真实程序运行状态。

## 修改位置与验证

修改菜单中文名称或固定入口在这里；执行行为归对应模块。

在 `frontend/` 运行 `npm run check` 和 `npm run build`；交互变化再运行 `npm run test:e2e` 并目视检查。不能为绕过检查而放宽模块依赖规则。
